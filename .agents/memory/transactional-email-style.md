---
name: Simix email visual style
description: Durable visual rules shared by transactional emails and admin campaigns.
---

All Simix emails, including authentication, recharge and admin campaigns, use the same reference-led visual language: pale gray page, dark brand banner, white card, violet Simix accents and Arial/Helvetica typography.

**Why:** Email clients strip or inconsistently support external CSS and webfonts; inline styles and a system font stack keep the professional reference look reliable in Gmail, Outlook, and mobile clients.

**How to apply:** Keep registration OTPs, inactivity verification, password reset, recharge confirmations, admin campaign rendering and campaign previews visually aligned. Keep dynamic values escaped and never expose codes in logs.
